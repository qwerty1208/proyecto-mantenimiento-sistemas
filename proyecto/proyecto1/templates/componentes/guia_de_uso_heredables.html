📚 Guía Rápida de Componentes para el Frontend

Copia y pega estos fragmentos de código directamente en tus vistas HTML.

1. Alertas de Notificación

Muestra mensajes de éxito o error en la pantalla.

Alerta de Éxito (Verde)

<alerta-notificacion mensaje="El platillo se guardó correctamente" tipo="exito"></alerta-notificacion>

Alerta de Error (Rojo)

<alerta-notificacion mensaje="Ocurrió un error de conexión" tipo="error"></alerta-notificacion>

2. Botones Reutilizables (Formularios y Enlaces)

Puedes cambiar el texto, el tipo (primario o secundario) y agregar un enlace para que el botón te lleve a otra página.

A) Botón Normal (Para guardar datos o enviar formularios)

No lleva el atributo 'enlace'. Se comporta como un botón nativo.

<boton-reutilizable texto="Ingresar al Sistema" tipo="primario"></boton-reutilizable>

B) Botón de Navegación (Para ir a otra página)

Lleva el atributo enlace="/ruta". Funciona idéntico a una etiqueta <a>.

<boton-reutilizable texto="Ir al Dashboard" tipo="primario" enlace="/dashboard"></boton-reutilizable>

C) Botón Secundario (Gris) con Enlace

<boton-reutilizable texto="Cancelar y volver al menú" tipo="secundario" enlace="/"></boton-reutilizable>

3. Tarjetas de Platillos y Popovers (¡Automáticos!)

No necesitas escribir etiquetas <tarjeta-platillo> a mano. El sistema de JavaScript ya se encarga de ir a la base de datos, dibujarlas y hacer que aparezca el Popover al pasar el cursor.

¿Qué debes hacer tú para que aparezcan?

Solo necesitas poner este contenedor vacío en tu HTML. JavaScript hará la magia inyectando las tarjetas adentro:
<div id="contenedor-platillos" class="body-rejilla-platillos 2 body-dishes-grid"></div>
